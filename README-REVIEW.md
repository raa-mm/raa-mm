# Design and engineering review

Scores are deliberately conservative. "Not verified" means it could not be checked in the environment that built this repository.

## Scores (after two improvement passes)

| Category | Score | Notes |
| :-- | :-: | :-- |
| Visual identity | 8 | One memorable motif (agent network) used consistently; dark violet/cyan system from the brief. Illustrations are abstract by design. |
| Typography | 8 | Clear scale; limited to system fonts because SVG-in-`<img>` cannot load web fonts. Appearance varies slightly by OS. |
| Hero | 8 | Name, title and motif readable at a glance. Tagline is README text, not image text, so it stays legible on phones. |
| Projects | 8 | Identical card frame and section pattern (problem, what it is, stack, status). No repository links because none were verified. |
| Technology | 8 | Only technologies Ram listed; grouped in eight areas; no percentages. |

| Contribution art | 7 | Generated by real workflows, never faked. Not verified: action behaviour and the exact 3D output file name (`profile-night-view.svg`) were not re-checked online. The workflow fails with a clear message if that name is wrong. |

| Performance | 8 | All custom assets under 4 KB each; no embedded data; only three external images. |
| Accessibility | 8 | Every image has alt text; every SVG has title (cards and banners also desc); animation hidden under reduced motion. Contrast of secondary text on dark surfaces is adequate but unmeasured. |
| Maintainability | 8 | Content register, design tokens, card template, validator and maintenance guide. |
| Accuracy | 9 | Every claim traced in `docs/PROFILE-CONTENT.md`; nothing invented. Project problem statements and philosophy bullets are written wording to confirm. |

## Pass 1 (structure and function)
- Chose local SVG chips and link buttons over skillicons/shields: fewer external dependencies, consistent style, and no uncertain icon names.
- Dropped the typing animation, activity graph and capsule-render: not reliable or not additive.
- Snake publishes with plain git instead of a third-party publishing action; unchanged output creates no commit.
- Validator written, then tested with planted faults (see below).

## Pass 2 (visual polish and QA)
- Fixed a stray animated dot at the SVG origin before its delayed animation began.
- Fixed two connector lines that did not render (gradient stroke on a zero-height line) in the APRS and SkillLens cards.
- Fixed a label overlapping a bar in the SkillLens card.
- Fixed the validator's host check, which wrongly flagged a URL with a query string.

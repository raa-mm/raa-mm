# Project card template

Card SVG: copy any `assets/project-*.svg`. Keep the frame (rect, panel, grid, accent bar), replace the illustration group, name, subtitle, status text and the `<title>` / `<desc>`.

README block:

```markdown
### Project name

<img src="assets/project-name.svg" alt="Project name card: one-line subtitle, status" width="100%">

**Problem.** One sentence about who struggles with what.

**What it is.** Two or three sentences. Use "building", "exploring" or "designed to" for anything not shipped.

<img src="assets/icons/chip-..." alt="..." height="32"> ...

**Status.** In development | Exploratory | Building | Released
**Links.** Repository and demo only if public and opened by you.
```
